# Number Facts via Workers AI on the same Worker

Number Facts come from Cloudflare Workers AI on the same Worker that serves the static site (not Numbers API, not a separate Worker). The browser calls a same-origin `/api/fact` endpoint. Successful facts are cached in `localStorage` by integer key (no TTL) to stay within the Workers Free Neurons budget; null results are not cached so a later view can retry. Tone is chosen at random (normal vs snarky) when a fact is produced. The model must prefer well-known facts; if it abstains, the Worker may use a small deterministic math fallback (prime / square / factors). This reintroduces live facts after ADR 0003’s deferral and adds a small server runtime beside `adapter-static` assets.
