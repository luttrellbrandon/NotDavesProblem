# Number Facts via Useless Facts + Workers AI rewrite

Number Facts are built in the Worker: fetch a random English fact from the [Useless Facts API](https://uselessfacts.jsph.pl/) (`GET /api/v2/facts/random?language=en`), then ask Workers AI (`@cf/meta/llama-3.2-3b-instruct`) to rewrite it into one short retirement joke that weaves in that trivia, the countdown Primary Number `n`, and its Countdown Unit. The browser only calls same-origin `/api/fact`. Successful jokes are cached forever in `localStorage` keyed by `n` + unit (see [ADR 0008](./0008-fact-cache-by-number-and-unit.md)); nulls are not cached. Any upstream or rewrite failure returns `fact: null`. Same-origin request gating remains. Supersedes [ADR 0006](./0006-numbers-api-worker-proxy.md) (Numbers API is down / HTTP-only). Requires the Worker `AI` binding (Workers Free Neurons quota).
